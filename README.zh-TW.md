# 🐥 小群 Swarmlings

一款像素風的虛擬寵物養成遊戲。你在草地上發現一隻毛茸茸的小生物。這裡有很多果子和水，**放著不管牠也會自己生活、分裂繁殖**（餵食、洗澡、玩球、摸摸只是加分）；數量多了之後，牠們開始自己找食物、砍柴、蓋房子，發現火、農耕、語言與文字，最後蓋出一座紀念碑並「醒來」，開始反過來觀察你、問你問題，最後給你一份「牠們對你的觀察結果」。

*A pixel-pet sim. Feed them, wash them, watch them multiply — and then watch them start watching you.*

單一 HTML 檔、零相依。**直接用瀏覽器開啟 `index.html` 就能玩**，介面有繁體中文與英文（自動偵測，右下角可切換）。

![demo](docs/demo.gif)

_一隻小生物在約 15 秒的縮時影片裡長成一座村落（道路、農田、四季、世代）。_

## 玩法

| 工具（快捷鍵） | 作用 |
|---|---|
| 🍎 餵食（1） | 點草地丟下蘋果，附近的小生物會去吃 |
| 🧼 洗澡（2） | 點（或拖曳）小生物幫牠洗乾淨 |
| ⚽ 玩球（3） | 點草地放球，牠們會追著踢 |
| ✋ 摸摸（4） | 點（或拖曳）小生物，提升心情 |
| 🔍 查看（5） | 點任何東西看資訊卡：小生物（名字、年齡、世代與父母、職業、住處、在做什麼、三項需求；放大時鏡頭會跟著牠）、建築（功能、住戶、農田生長）、果樹與樹苗、岩石、墓碑、兔子、魚、鳥、廣場（庫存） |
| 🌱 地形（6） | 種樹、放石頭、挖池塘（十字形 5 格，永不乾涸，會有魚住進來）、填平；游標上有預覽（綠框可放、紅框不行）。改動會存檔 |
| ✨ 篩選（F） | 勾選類別（幼兒、長者、各職業、餓肚子、很髒、心情差、沒有家、各種建築、成熟的農田、果樹、樹苗、岩石、墓碑、兔子、魚、鳥），畫面上所有符合的東西都會加上外框；每個類別用不同顏色，可多選，按鈕上顯示數量 |
| 📜 歷史（H） | 世界歷史：依時間記錄重大事件（發現、第一座建築、人口里程碑、世代、長者壽終、冬天、覺醒…），最新在上，並有人口、世代、誕生、壽終、餓死等統計 |

三種需求（飽足、清潔、心情）都滿足一段時間，小生物就會分裂；牠們會自己摘果子、去岸邊洗澡、找朋友聊天，所以你可以只是看。空白鍵暫停，可調 1× / 3× / 10× / 30× / 100× 速度（100× 約十秒看完整個聚落成形），遊戲會自動存檔。

## 事件

每隔幾分鐘會隨機發生一件事，依季節與時間而定，並寫進歷史：**乾旱**（夏天；湖水退去、果子變少、畫面泛黃）、**豐收**（秋天；農田一夜成熟、收成 +50%、金黃葉子飄落）、**流星雨**（夜晚；流星劃過，結束後留下 2 塊隕石）、**極光**（冬夜；天空舞動的彩帶）、**節慶**（白天；大家去廣場跳舞，掛滿彩旗與彩紙）。事件會提升心情，畫面上方會顯示目前的事件。

## 成就與紀錄

約 30 個成就（第一場雪、三度寒冬、人口 50／100／300、五代／十世傳承、發現全部發明、看過各種事件與結局、親手改變地形…），加上最高人口、最多世代、最快蓋出紀念碑、看過的結局數等紀錄，存在瀏覽器裡（localStorage），跨局保留。工具列「成就」查看。

## 環境音與音樂

全部用 WebAudio 即時合成，沒有音檔：雨聲與風聲（濾波雜訊）、隨季節與晝夜變化的五聲音階隨機旋律（春夏明亮、秋天低沉、冬天稀疏如鈴聲；節慶、流星雨、乾旱另有旋律）、白天鳥叫、夏秋夜裡蟲鳴。「音樂」按鈕可單獨關閉旋律，喇叭按鈕則全部靜音；30× 以上快轉時旋律自動停止。瀏覽器規定要先點一下畫面才會發聲。

## 更多建築與職業

除了小屋、房屋、營火、果園、圖書館、紀念碑，人口與發現到位後還會蓋：**水井**（有工具；洗澡改去水井）、**碼頭**（有工具；伸進湖裡，漁夫出海捕魚）、**倉庫**（有火；一趟能多搬果子）、**磨坊**（有農耕；收成 +50%）、**市集**（有語言；聚會聊天的社交中心）。新增職業：**農夫**（顧農田、收成）、**漁夫**（有碼頭才會有）。建築依種類選地段（市集、圖書館、紀念碑在第一圈，磨坊在外圍，碼頭在岸邊）。

## 世代與壽終

每隻小生物有父母、世代與壽命（約 5～7.5 天）。孩子優先住進父母家；快到壽命時頭髮變白、走得慢（長者）。壽終後會在地圖上的墓園留下墓碑（最多 30 座，超過就換掉最舊的），附近幾隻小生物會走去送行。最初的那一隻走了會有特別的訊息。查看工具的資訊卡會顯示世代與父母。人口低於 4 隻時不會老死，避免整個聚落滅亡。

## 結局

除了原本的園丁、建築師、旅人、旁觀者，還有：**沉默者**（幾乎沒插手）、**嚴父**（常忽略又愛掌控）、**守護者**（有求必應）、**玩伴**（常陪玩球）、**見證者**（傳了 6 代以上、送走 15 位以上長者）。結果畫面也會顯示世代數與送走的長者數。

## 農田與野生動物

發現「農耕」後蓋的農田會真的長作物：春天播種、逐漸長高，入秋成熟變金黃，採集者會去收成（一次 +16 顆果子）；冬天有霜害，沒收成就歸零。人口越多，農田越多（最多 6 塊）。世界裡還有純裝飾的野生動物：湖裡的魚（冬天結冰時看不到）、白天飛過天空的鳥、會躲人的兔子。

## 工具列

分成兩排：上排是**工具**（餵食、洗澡、玩球、摸摸、查看、地形）；下排由左到右是**時間**（暫停、1×～100×）、**視角**（縮放）、**面板**（篩選、成就、歷史）與**選單**（音樂、聲音、語言、重來與快捷鍵一覽）。視窗變窄時文字標籤會自動隱藏、只留圖示；滑鼠移到按鈕上會顯示說明與快捷鍵。

## 縮放與平移

滾輪縮放（1×～6×，以游標為中心），右鍵或中鍵拖曳平移；餵食／玩球工具下，左鍵拖曳也能平移（沒有拖動才算「點一下」）。觸控：雙指縮放、單指拖曳平移。鍵盤：`+` `-` 縮放、`0` 還原、方向鍵／WASD 平移；工具列也有 `-` `+` 按鈕。

## 四季與生態

每季 2 天，地表會換裝並淡入淡出：春（樹上開櫻色小花）→ 夏（深綠）→ 秋（橘紅落葉色）→ 冬（白雪、光禿的樹、湖面結冰、下雪）。冬天果實再生較慢。湖泊水位也隨季節漲退：春天融雪水位最高，夏天乾旱最低（淹水時會避開建築、樹和廣場；被淹到的小生物會被沖上岸）。樹會自己落種、長出樹苗，森林慢慢蔓延；聚落也隨時間往外長。

## 每一局的世界都不一樣

地形由種子隨機生成：湖泊、森林、岩丘的位置都不同，還有春綠、秋橙、青翠三種配色（同一個種子永遠是同一張地圖，可用網址分享）。聚落先有路再有房：從廣場放射出主幹道，疊上幾圈環路（遇到湖就跨過去），房子只蓋在路旁的地段上，由內往外一圈圈填滿，蓋房的地方樹會讓開，路只鋪到聚落需要的範圍；里程碑（紀念碑、圖書館）在第一圈，果園在外圍，營火在廣場邊。地段蓋滿就是這座城的人口上限；每隻小生物會住進自己的房子，白天工作，晚上走回家門口睡覺，有人住的房子會亮窗光、冒炊煙。偶爾還會下雨。

## 大致的進程（1× 約 13～16 分鐘，可用 30×/100× 加速）

1. **養成**：一隻小生物，全靠你照顧。
2. **群體**（8 隻以上）：牠們開始自己找食物，依需求分工成採集者、伐木者、採石者、建造者、思考者。
3. **文明**：發現工具、火、農耕、語言、文字，蓋出小屋、房屋、營火、果園、圖書館，最後是紀念碑。
4. **覺醒**：紀念碑亮起，牠們全部轉頭看你，問你 6 個問題；有些開始拒絕被摸、被洗；最後全員排成一隻眼睛，給出你的性格分析。

## 像素風格

整個畫面（含介面）都是像素風：

- **字體**：[Cubic 11（俐方體 11 號）](https://github.com/ACh-K/Cubic-11)，SIL OFL 1.1 授權（`tools/Cubic11-OFL.txt`）。完整字體有 2.8MB，`tools/build-font.py` 只裁出遊戲用到的字（約 650 個，27KB）並以 base64 嵌進 `index.html`，所以仍是單一檔案、離線可用。
- **圖示**：約 30 個像素圖示用程式定義在 `index.html` 的 `IC` 表，取代所有表情符號。
- **介面**：方角階梯邊框、棋盤格暗化遮罩、分段式進度條、像素滑鼠游標。
- **畫面內文字**（泡泡、訊息、橫幅）直接畫在 320×180 的遊戲畫布上，跟世界一起整數倍放大。

新增或修改遊戲文字後，重新執行一次字體工具即可：

```
python3 -m venv .venv && .venv/bin/pip install fonttools brotli
.venv/bin/python tools/build-font.py
```
